Co-op Snake

A couch co-op take on the classic Snake, with grid-based movement, power-ups and power-downs.

Project information

Stack
Unity, C#
Mode
Single player and local co-op
Repository
github.com/tanya15gupta/Snake-Game

Details

Features

  • Grid-based movement for both snakes.
  • Single player and couch co-op modes.
  • Power-ups and power-downs that change how a run plays out.
  • Score tracking and collision handling between both players.
