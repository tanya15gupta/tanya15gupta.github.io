Chest System

A Clash Royale-style chest system built in Unity: modular, state-machine driven, and easy to drop into any project.

Project information

Stack
Unity, C#
Date
January 2023
Repository
github.com/tanya15gupta/Clash-Royale-Chest-System-Clone

Details

Features

  • Chest spawning, with any number of chests.
  • State machine handling locked, unlocked and unlocking states.
  • Queue for opening chests one after another.
  • Slot count can be expanded.
  • A modal window that adjusts itself to fit the message.

Patterns

  • Singleton for the managers.
  • MVC architecture.
  • State machine.
